## 需要外部条件才能收口

1. 在各工具自己的终端登录 Claude Code / Cline / Grok 后，执行极小只读任务及续接验收。Teamroom 不接收密码、验证码或 API Key。
2. 安装并登录官方 Cursor Agent CLI 后验证 `agent acp`；仅安装 Cursor 编辑器不足以通过验收。
3. 安装并验证官方 CodeBuddy CLI 后继续 WorkBuddy 执行适配；只实现公开接口，先确认权限白名单与 MCP 隔离，再开放真实派发。
4. 签名证书、系统通知实际投递及自动更新属于后续发布验收，不由源码测试替代。
