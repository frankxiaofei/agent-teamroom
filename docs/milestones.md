# Milestones

每个里程碑独立可用，完成定义以 Tasks 的验收证据为准。预估为单人有效开发时间，不是交付日期承诺。

| Milestone | 可交付结果 | 预计工作量 | 完成定义 |
|---|---|---|---|
| M1 · 本地群聊基础 | 桌面工作群、卡通员工、@ 路由、演示与 SQLite | 2–3 天 | T01–T05 完成；桌面启动、接收人边界与重启烟测通过 |
| M2 · Codex 真实闭环 | stdio 执行、流式进度、续接、审批、取消与额度 | 3–5 天 | T06–T10 完成；协议夹具与真实账户/极小推理分别验证 |
| M2.1 · 主动汇报 | 状态事件、半小时增量、18:00 日报、托盘驻留与补报 | 2–3 天 | T23–T26 通过；无变化不刷屏、跨午夜、休眠与重启去重验证 |
| M2.2 · 群内讨论 | 问题卡片、只读咨询、结论确认与原任务续接 | 3–4 天 | T27–T31 通过；轮次与人数上限、失败恢复、权限拒绝与明确继续验证 |
| M3 · Claude 与 OpenCode | 两个额外真实员工，统一任务/事件语义 | 4–6 天 | T11–T13 完成；每种工具均有本机任务与失败测试 |
| M4 · ACP 与 WorkBuddy | Cursor / Cline 接入及 WorkBuddy 能力证据 | 4–7 天 | T14–T16 完成；不承诺公开接口未提供的控制能力 |
| M5 · 可日用与分发 | 可信日报、速度指标、账户来源、Windows 包与恢复 | 5–8 天 | T17–T20 完成；安装/升级/重启/恢复验收通过 |
| M6 · X 推荐与社区反馈 | README 演示、推荐串文、反馈入口与公开发布 | 1–2 天 | T21–T22 完成；发布前逐项核对实际能力和链接，发布后读回 URL |

## 当前开发批次

M1 与 M2 已交付源码开发预览。按用户新增需求，当前优先实现 M2.1 主动汇报与 M2.2 群内讨论，再推进 M3–M5；M5 的日报统计基础前移至 M2.1，效率比较与账户账单仍留在 M5。M6 的文案可以提前准备；面向普通用户推荐可安装版本须等待 M5 的分发验收。

## 发布条件

- 开发预览：M1/M2 源码与测试可公开，明确只有 Codex 真实适配器。
- 面向尝鲜开发者的 X 介绍：源码链接、截图、能力边界与运行步骤齐备，使用“building in public / 开发预览”措辞。
- 面向普通用户的正式推荐：至少两种真实工具完成本机验证，Windows 分发与恢复通过；禁止用演示多工具替代真实接入证据。
