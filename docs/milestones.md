| M1 · 本地群聊基础 | 桌面工作群、卡通员工、@ 路由、演示与 SQLite | 2–3 天 | T01–T05 完成；桌面启动、接收人边界与重启烟测通过 |
| M2 · Codex 真实闭环 | stdio 执行、流式进度、续接、审批、取消与额度 | 3–5 天 | T06–T10 完成；协议夹具与真实账户/极小推理分别验证 |

## 当前开发批次

本次交付 M1 与 M2 的源码开发预览。M3–M5 是后续开发，不把首个源码推送描述为完整产品。M6 的文案可以提前准备；面向普通用户推荐可安装版本须等待 M5 的分发验收。

## 发布条件

- 开发预览：M1/M2 源码与测试可公开，明确只有 Codex 真实适配器。
- 面向尝鲜开发者的 X 介绍：源码链接、截图、能力边界与运行步骤齐备，使用“building in public / 开发预览”措辞。
- 面向普通用户的正式推荐：至少两种真实工具完成本机验证，Windows 分发与恢复通过；禁止用演示多工具替代真实接入证据。
