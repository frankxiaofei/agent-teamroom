# 卡通员工素材

`public/avatars.webp` 是本项目界面使用的六宫格图集，由本次设计会话通过内置 ImageGen 生成并修改，保留了六位原创卡通角色与产品名牌。不是官方品牌吉祥物。Grok 使用独立的原创 SVG 石头机器人（`public/grok.svg`），带 Grok 名牌；没有修改原图集，也不是官方吉祥物。

形象顺序：珊瑚星星 Claude Code、白色机器人 Codex、绿色青蛙 OpenCode、紫色猫 Cursor、蓝色猫头鹰 Cline、水豚 WorkBuddy。

生成规格：premium rounded clay 3D cartoon employee atlas, 3 columns × 2 rows, consistent scale and soft lighting, original silhouettes, transparent output, each mascot with a physical ivory name badge bearing the exact corresponding product name. Names are functional identification, not a claim of endorsement.

素材与代码随本仓库提供；对应产品名称和商标归各自权利人所有。截图必须来自实际运行界面，公开时避免本机路径、任务正文中的私密信息和账户细节。
